Before you begin

Confirm you have what you need.

Gate filter

Three questions. All three must pass.

G1 — Repeatability

Is the task repeatable — same input type, same process, every time?

This is a prompt, not an agent. Write a skill or a one-shot prompt instead. Agents add maintenance overhead that isn't worth it for tasks that vary.

G2 — Output definition

Can you describe what "done" looks like in one sentence?

Write the sentence

Read that sentence. Does it have exactly one verb? Does it describe an output, not a process?

If you can't describe done in one sentence, the output isn't defined yet. Spec the output first — come back when you can write it.

G3 — Recurrence

Would you run this agent more than once a week?

If you'd run it less than weekly, the build and maintenance cost probably isn't worth it. Build a prompt instead — or come back when you're running this task more often.

All three gates passed. You have a repeatable task with a defined output and enough recurrence to justify the build cost. Next: structure the spec.
